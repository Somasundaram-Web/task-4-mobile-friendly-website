# Task 4 - Mobile-Friendly Website

## 📌 Project Overview

This project is an existing landing page updated to be mobile-friendly using CSS media queries.

The main goal is to make the website responsive and readable across desktop, tablet, and mobile screen sizes.

## 🎯 Objective

Convert an existing desktop-oriented webpage into a responsive website that works properly on smaller screens.

## ✨ Features

- Responsive header and navigation
- Mobile-friendly navigation layout
- Responsive hero section
- Responsive heading and paragraph sizes
- Responsive CTA button
- Responsive footer
- Flexible social links
- Multiple CSS media queries
- Prevents horizontal overflow
- Tested using Chrome DevTools Device Toolbar

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Chrome DevTools

## 📱 Responsive Breakpoints

The website was tested and optimized for:

- Desktop screens
- Tablet screens up to 768px
- Mobile screens up to 480px
- Small mobile screens up to 360px
